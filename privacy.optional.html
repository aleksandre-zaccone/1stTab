1stTab Privacy Policy

Optional release candidate 2.2.0 · October 18, 2026

Data processed

1stTab reads and edits your Chrome bookmarks when you use its library. It reads the current page title and URL only following a toolbar action. Bookmark notes, tags, favorites, preferences, migration snapshots and recovery backups are stored in chrome.storage.local on your device.

Sharing

Ordinary local operations do not upload your bookmarks or collect analytics. Optional Google Drive operations send the data described below only after you explicitly grant access and start the operation. Chrome may sync native bookmarks according to your browser settings; extension notes and tags do not automatically follow that sync. Opening a bookmarked URL connects to its website under that website’s own policies. Starter sites use bundled high-resolution icons. Other bookmark icons request a higher-resolution favicon from Chrome’s saved icons. If no saved icon is available, loading an icon requests /favicon.ico from that website without sending a referrer, bookmark notes, or tags. If loading fails, a first letter is shown.

Your controls

You may edit/delete bookmarks, export a copy, and import an export. Exported files contain saved URLs and notes: choose where to store and share them. Uninstalling removes extension storage but leaves native Chrome bookmarks. Migration preserves legacy metadata locally for recovery. Extension backups do not contain API keys or authentication tokens.

Permissions

bookmarks manages the native library; storage keeps local metadata and recovery data; sidePanel displays bookmarks while browsing; activeTab reads the current page after your toolbar click; favicon reads Chrome’s saved website icons for bookmark cards and list rows. No required external host access, history or hardware permissions. Optional identity permission and provider-specific host access are requested when enabling Google Drive.

Support

Report privacy questions through the project issue tracker. Do not post private bookmarks in public reports.

Optional Google Drive backup

If you connect and upload, Google receives the bookmark export including notes, tags, favorites and portable appearance/view preferences in the app-private Drive appDataFolder. Only drive.appdata is requested; no Calendar, Tasks or Gmail access. Drive returns the authorized account identifier and display email/name to verify the connection. These fields and operation status/timestamps are stored locally, excluded from exports, and cleared on disconnect. Tokens are handled by Chrome’s identity API and are not logged or exported. There is no automatic upload. Backups remain until you choose Delete backup. Restores require an additive import preview with duplicate and metadata-difference counts and can create duplicates. Preference restoration is optional; a local recovery snapshot preserves previous data and preferences. Disconnect clears Chrome cached tokens and removes extension permission; you may also revoke the app through Google account settings. Google processing follows Google’s privacy policy.
