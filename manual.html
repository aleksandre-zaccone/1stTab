Your library, one tab away

Open a new Chrome tab to see your bookmarks. Chrome may ask you to confirm the new-tab change after installing or reloading 1stTab. Your library uses Chrome’s native bookmarks, so changes also appear in Chrome’s bookmark manager.

  1. Save a page. Click the extension’s toolbar icon on a normal website, or choose Add bookmark in your library.
  2. Give it context. Pick a folder, add comma-separated tags, and write an optional note.
  3. Find it again. Search its title, URL, tags, or note. Click the bookmark title to open the website.
The design previews contain sample bookmarks. Installing the extension does not add those samples to your real library.

Folders & drag and drop

Use New collection to create a folder. The + on a tree row creates a subfolder; the pencil renames it and the trash icon opens a deletion preview. Deleting a folder also deletes its contents after confirmation. Chrome roots and managed bookmarks are protected.

Drag a bookmark onto a folder to move it immediately. Select several bookmarks first to move them together. Drag between bookmarks in the same folder to save a new manual order. Name A–Z and Newest first change only the displayed order.

For keyboard or touch use, select bookmarks and choose Move selected. The selection bar also offers bulk tagging and deletion.

Drag the right edge of the folder sidebar to resize it. Double-click the edge to reset its width. With the divider focused, use Left/Right arrows for 10-pixel steps, Shift + arrow for 50, or Home/End for the minimum/maximum. Width is remembered on this device. On small screens the Collections button opens a drawer.

Search & filters

Search stays at the top while you scroll. Press Ctrl / ⌘ + K to focus it.

Show filters reveals collection, tag, domain, and favorites filters in both card and list views. Hiding the filters keeps them applied; a badge shows the active count. Use Reset filters to clear them and search. Clicking a tag filters by that tag.

Use the star on a bookmark to add it to Favorites. Select Favorites in the sidebar or the top navigation to see your saved favorites.

Make it yours

The gear beside search opens the separate Settings page. Changes save automatically. Back to library returns to your current folder, search, and selections during the same session.

  • Appearance: choose Prism, Atelier, Studio, Pop, or Enterprise, with Light, Dark, or Follow system mode.
  • Text & icons: increase text up to 140% and icons up to 150% independently.
  • Workspace: choose cards or a compact list, display sort, spacing, note visibility, and reduced motion.
  • Card shapes: Rectangle, Square, Rounded, Circle, or Sphere. Use Preview in card view to try the shape. List view stays compact.

Reset appearance restores the default theme, sizes, card shape, sidebar width, spacing, notes, and motion preferences. It keeps your bookmarks, selected view, sort order, and expanded folders.

Export, import & cleanup

Open Settings → Library tools.

  • Export library downloads a JSON backup of bookmarks, tags, and notes. It does not include API keys.
  • Import export validates a 1stTab JSON file, shows counts, and asks you to choose a destination. Confirming adds a separate Imported folder without overwriting existing bookmarks.
  • Review cleanup lists exact-URL duplicates and empty folders. Choose items, review the deletion, then confirm. Nothing is deleted automatically.

Undo & recovery

Undo last edit reverses the latest supported change, including bookmark metadata or deleted folder contents. It refuses to overwrite conflicting edits made afterward in another surface.

Restore snapshot previews and imports the saved pre-edit library snapshot additively, so it may create duplicates. A recovery snapshot is not a permanent backup archive: export a copy before extensive changes.

Keyboard & side panel

ControlAction
Ctrl / ⌘ + KFocus bookmark search, returning from Settings if necessary.
Alt + Shift + POpen the side panel (Chrome shortcut settings may override this).
EscapeDismiss a dialog or close the mobile folder drawer.
Tab / Shift + TabMove through buttons, inputs, and the sidebar divider.

The side panel, new-tab manager, and Settings share bookmarks and local preferences. Settings is a page; it is not dismissed with Escape.

Local data & optional services

No account is required for the local library. Bookmarks follow Chrome’s own sync settings. Tags, notes, favorites, appearance preferences, and recovery snapshots stay in this extension’s local storage. Opening a bookmark connects your browser to that website. See the Privacy page for details.

The separate optional package includes disabled-by-default AI organization and Google Drive backup. Each flow explains its recipients and data before requesting access. AI suggestions require review before applying; Drive restore is additive. Google sign-in requires the publisher’s OAuth configuration for the installed extension ID. Provider terms and charges may apply.
