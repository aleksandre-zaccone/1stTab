1. The Dashboard

1stTab replaces your default Chrome new-tab page with a two-column widget dashboard. The top bar contains the global search field, a greeting, and navigation icons for Settings, the Bookmarks Manager, and the Side Panel.

  • Arranging Widgets: Drag any widget card by its title bar and drop it into the left or right column to reorder your layout. Changes are saved automatically.
  • Enabling / Disabling Widgets: Open Settings → Widgets to toggle individual widgets on or off. Hidden widgets are removed from the layout but your data (notes, todos, etc.) is preserved.
  • Background Image: Set a custom background image in Settings → Appearance → Background. Free users can upload one image; Plus users have unlimited uploads.

3. Focus Mode

Press F on the dashboard to enter Focus Mode. The screen dims and a large clock with today's date fills the center — ideal for Pomodoro breaks or minimizing distractions. Press F or click anywhere to exit.

4. Global Search

Press Ctrl+K (or click the search bar in the top nav) to open Global Search. As you type, a dropdown shows matching bookmarks in real time. Use ↑/↓ to highlight a result and Enter to navigate. Press Escape or click outside to close.

5. Dashboard Widgets

Each widget can be toggled independently in Settings → Widgets.

Bookmarks

A visual grid of your most important sites. Click any bookmark to navigate. Use the / shortcut or the filter field at the top to search by title. Add or remove bookmarks directly from the grid using the add (+) button. Bookmarks are read from and written to your Chrome bookmarks.

Notes (Scratchpad)

A persistent text area for quick thoughts, links, or snippets. Content is saved automatically as you type to chrome.storage.sync so it's available across your devices. Free users have a 2,000-character limit; Plus users have unlimited storage.

To-Do (Today)

A daily task list synced via chrome.storage.sync. Add tasks with the input field, check them off as you complete them, and delete them individually or all at once. Free users can store up to 25 todos; Plus users have unlimited todos.

Time & World Clocks

Displays your local time prominently and lets you add world clocks for other time zones. Free users can add up to 3 world clocks; Plus users can add unlimited clocks. Plus users can also choose from three analog clock face styles (see Themes).

Weather

Shows current conditions, temperature, and a short forecast. Configure your city in Settings → Weather. Weather data is fetched from Open-Meteo. No API key is required.

Pomodoro Timer

A built-in Pomodoro timer with Work / Short Break / Long Break phases. Start, pause, or reset with the on-widget controls. An audio chime plays at the end of each phase. Configure phase durations in the widget.

Cryptocurrency Prices

Shows live prices and 24-hour change for cryptocurrencies you configure. Data is fetched from CoinGecko and refreshed every 60 seconds. No API key required.

Foreign Exchange (FX) Rates

Displays real-time exchange rates for currency pairs you choose, with a configurable base currency. Rates are sourced from ER-API and refreshed hourly. No API key required.

Browser History

Shows your most recently visited pages, pulled from Chrome's local history using the chrome.history API. No history data leaves your device. Clear results by clearing your Chrome browsing history.

Stock Quotes Plus

Displays live stock prices and change percentages for tickers you configure. Requires a free Finnhub API key, which you enter in Settings → Plus → API Keys. Quotes refresh every 5 minutes.

6. Side Panel

Open the Side Panel with Alt+Shift+P, the toolbar button, or the panel icon on the dashboard. The panel stays open while you browse other tabs. Use the detach button to pop the panel into a floating window.

The panel has six tabs:

Bookmarks

Browse, search, and open your Chrome bookmarks from the panel while on any tab.

Calendar Plus

Shows upcoming events from your Google Calendar for today and the next 3 days, grouped by date with color-coded dots. Events refresh every 15 minutes. Requires connecting your Google account in Settings → Plus → Google. Use the "+" button to add a new event (opens Google Calendar).

Tasks Plus

Displays your Google Tasks inline. Add new tasks with the input at the top, check them off to mark complete, and see overdue tasks highlighted in red. Requires a connected Google account.

Tabs

A live list of all open tabs across your browser windows. Search tabs by title or URL, click to switch to any tab, use the mute button to silence audio, or click the close button to close a tab. Recently closed tabs appear at the bottom and can be restored with a click.

System Monitor

Displays real-time system information refreshed every 2 seconds:

  • CPU: Current usage percentage (delta from last reading)
  • RAM: Used vs. available memory with a progress bar
  • Storage: Disk usage for your system drive

All system data is displayed locally only and is never transmitted.

AI Bookmark Assistant

A conversational AI chat interface that uses your bookmarks as context. Ask the AI to find bookmarks, suggest categories, summarize a site, or answer questions. See Section 12 — AI Features for setup instructions.

7. Bookmarks Manager

Click the bookmarks icon in the top-right of the dashboard to open the full Bookmarks Manager in a new tab.

  • Tree View: Browse all your Chrome bookmark folders in a collapsible sidebar tree.
  • Drag and Drop: Drag bookmarks and folders to reorganize your collection.
  • Create & Edit: Add new folders, edit bookmark titles and URLs, and delete items.
  • Search: Filter all bookmarks by title or URL in real time.
  • Smart Tags Plus: When AI is configured, saving a bookmark automatically suggests 3 tags using AI analysis of the URL and title. Tags help you filter and categorize bookmarks without manual effort.

8. Themes & Appearance

Light / Dark

Toggle between Light and Dark themes in Settings → Appearance → Theme. The theme applies across the dashboard, side panel, settings, and all extension pages.

Arcade Mode

Arcade mode transforms the dashboard with a retro aesthetic. Choose a variant in Settings → Appearance → Arcade Cabinet:

  • Pac-Man — yellow and blue palette
  • Space Invaders — green on black terminal style

Clock Faces Plus

Plus users can select an analog clock face style in Settings → Appearance → Clock Face:

  • Minimal — clean, modern SVG hands
  • Retro — warm, vintage dial style
  • Pixel — blocky pixel-art style

Background Image

Upload a custom background image in Settings → Appearance → Background. The image is stored locally. Free: 1 image. Plus: unlimited.

Typography

Adjust the base font size for the dashboard in Settings → Appearance → Typography.

Custom CSS Plus

Plus users can enter any CSS in Settings → Plus → Custom CSS. The CSS is injected as a <style> tag on the dashboard, giving you full control over colors, spacing, fonts, and layout. Changes apply instantly as you type.

10. 1stTab Plus

1stTab Plus unlocks premium features. To activate, purchase a license key and enter it in Settings → Plus → License.

Plus features include:

  • Google Calendar in the Side Panel (today + 3 days)
  • Google Tasks in the Side Panel (inline add, complete, overdue alerts)
  • Google Drive cloud backup (manual + automatic daily)
  • Stock Quotes widget (Finnhub)
  • Analog Clock Face selector (3 styles)
  • Custom CSS editor
  • AI Smart Bookmark Tagging
  • Unlimited world clocks (free: 3)
  • Unlimited todos (free: 25)
  • Unlimited notes (free: 2,000 characters)
  • Unlimited background images (free: 1)

11. Backup & Sync

Chrome Sync

Preferences and todos stored in chrome.storage.sync automatically sync across your Chrome devices when you are signed into Chrome with the same Google account.

Manual Export / Import

Go to Settings → Plus → Backup to export your entire 1stTab configuration as a JSON file. Import a previously exported file to restore settings on a new device or after reinstalling.

Google Drive Backup Plus

Connect your Google account in Settings → Plus → Google to enable Drive backup. Drive backups are stored in a private app folder that only 1stTab can access.

  • Backup Now: Create a backup immediately
  • Auto-Backup: Enable daily automatic backups (runs once per day via a background alarm)
  • Restore: Browse the last 5 backups and restore any of them
  • Disconnect: Removes Drive access and deletes the backup folder

12. AI Features

1stTab integrates three optional AI providers. Your API key is stored locally and sent only to the selected provider's API — never to 1stTab servers.

Setup

  1. Go to Settings → Plus → AI & API Keys
  2. Choose your AI provider: Anthropic Claude, OpenAI, or Google Gemini
  3. Paste your API key from the respective provider's developer console
  4. Optionally select the model (defaults: Claude Haiku, GPT-4o mini, Gemini 1.5 Flash)

AI Bookmark Assistant (Side Panel)

Open the Side Panel and select the AI tab. The assistant has access to your bookmark titles and URLs as context. Example prompts:

  • "Find all my bookmarks related to design tools"
  • "Which of my bookmarks is most likely about machine learning?"
  • "Suggest folders to organize my bookmarks"

Chat history is maintained for the current panel session. A "Summarize" action compresses the conversation if it grows long.

Smart Bookmark Tagging Plus

When you save a bookmark, 1stTab automatically sends the title and URL to your configured AI provider and receives 3 suggested tags. You can accept, edit, or dismiss the suggestions. Tags are stored locally alongside the bookmark.
