# 1stTab v2.1.0 — Import where you choose

- Imports now add folders and bookmarks directly to the destination folder you choose. A separate "Imported" folder is no longer created. Existing bookmarks are not overwritten, and a local snapshot is still saved first.
- The library shows the installed version next to the 1stTab name, so you can see which release you are using.

Tags, notes and favorites in an export are kept when you import it. If an import stops partway, the bookmarks added before the problem remain in the destination folder with their tags and notes.

Known limitation: folders with the same name are not merged. Importing a "Search" folder into a destination that already has one adds a second "Search" folder.
