# 1stTab v2.0.0 — A focused bookmark manager

1stTab now focuses on one purpose: saving, organizing and finding your Chrome bookmarks.

- Open your bookmark library in every new tab, or use the side panel while browsing.
- Organize folders and nested folders with a resizable tree, drag-and-drop moves and manual ordering.
- Browse compact lists or customizable cards. Search and filter by collection, tag, domain and favorites.
- Add bookmark notes, tags and favorites; save the current page from the toolbar.
- Review import/export, duplicate cleanup and recovery snapshots before making changes.
- Use a separate Settings page with themes, text/icon sizes, card shapes, a manual and terms.

The standard v2 package stores extension metadata locally and requires no account. Native Chrome bookmark sync continues according to your browser settings. Google Drive sync and synchronization between Google accounts are upcoming features and are not included in this release.

This release replaces the previous multipurpose dashboard. The optional AI/Drive integration candidate is not part of the published package.

Known limitation: import supports HTTP, HTTPS and FTP links. Native bookmarklets, browser-internal links and file URLs cannot be re-imported unchanged from an export.

Chrome Web Store submission and review status are tracked separately from this GitHub release. A GitHub release does not by itself mean the Chrome Web Store version is available.
